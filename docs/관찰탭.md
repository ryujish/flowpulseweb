# 관찰 탭 기획

## 1. 문서 목적

본 문서는 FlowPulse의 세 번째 하단 탭인 `관심 종목`의 역할과 화면 구성을 정의한다.

관심 종목 탭은 단순히 종목을 저장하는 즐겨찾기 화면이 아니다.

두 번째 `종목` 탭에서 사용자가 `관찰 시작`을 누른 이후 다음 과정을 지속해서 관리하는 실행 허브다.

- 신호 변화 관찰
- 진입 확인
- 분할진입 기록
- 추가진입 중단 판단
- 수급 약화 감지
- Rally Exit 확인
- 분할 익절 및 전량청산 기록
- 당일청산 확인
- 사후검증 연결

핵심 흐름은 다음과 같다.

> 후보 발견 → 관찰 시작 → 신호 변화 추적 → 분할진입 → 청산 확인 → 사후검증

---

## 2. 하단 탭 구조

FlowPulse의 하단 메뉴는 다음과 같이 구성한다.

| 순서 | 탭 | 역할 |
|---|---|---|
| 1 | Flow | 시장·업종·투자주체별 수급 흐름 파악 |
| 2 | 종목 | 후보 종목 탐색, 검색, 신호 발견 |
| 3 | 관심 종목 | 관찰·분할진입·청산 진행 관리 |
| 4 | Feed | 신호 발생·변화·종료 결과 확인 |
| 5 | Me | 사용자 기록·사후검증·설정·BYOK 관리 |

기존의 독립적인 `AI` 탭은 하단 메뉴에서 제외한다.

AI 기능은 별도의 목적지가 아니라 다음과 같이 사용자의 판단이 필요한 화면에서 제공한다.

- 종목 신호 카드의 `AI 해설`
- 관찰 카드의 `현재 변화 설명`
- Rally Exit 카드의 `청산 근거 설명`
- 사후검증 화면의 `결과 요약`

## 3. 관심 종목 탭의 핵심 정의

> 관심 종목 탭은 사용자가 저장한 종목과 현재 관찰·진입·청산 중인 종목을 한곳에서 관리하는 공간이다.

일반적인 관심종목 화면처럼 종목명, 현재가, 등락률만 보여주는 목록으로 만들지 않는다.

FlowPulse의 관심 종목 탭은 다음 질문에 답해야 한다.

- 지금 바로 확인해야 할 종목은 무엇인가?
- 관찰 중인 신호가 강화됐는가?
- 신호가 약화됐는가?
- 진입 확인 조건이 충족됐는가?
- 추가진입을 중단해야 하는가?
- 프로그램·외국인·기관 수급이 매도로 전환됐는가?
- Rally Exit 조건이 발생했는가?
- 무효 조건이 발생했는가?
- 장 마감 전에 정리해야 할 종목은 무엇인가?

## 4. `관심 등록`과 `관찰 시작` 구분

`관심 등록`과 `관찰 시작`은 서로 다른 기능이다.

| 구분 | 관심 등록 | 관찰 시작 |
|---|---|---|
| 목적 | 종목을 저장하고 나중에 다시 확인 | 특정 수급 신호의 진행 과정 추적 |
| 시작 위치 | 검색 결과·종목 상세 | 두 번째 탭의 신호 카드 |
| 신호 스냅샷 | 선택 | 필수 저장 |
| 확인 조건 | 없음 | 저장 |
| 무효 조건 | 없음 | 저장 |
| 분할진입 기록 | 지원하지 않음 | 지원 |
| Rally Exit 감시 | 기본 변화만 제공 | 신호 단위 추적 |
| 당일청산 관리 | 없음 | 지원 |
| 종료 후 검증 | 없음 | 사후검증에 자동 연결 |

관심 종목 탭은 다음 세 영역으로 구분한다.

1. 진행 중
2. 일반 관심
3. 오늘 종료

### 4.1 진행 중

`관찰 시작`을 누른 종목을 보여준다.

진입 여부와 관계없이 현재 활성화된 신호를 추적한다.

### 4.2 일반 관심

별표 또는 `관심 등록`만 누른 종목을 보여준다.

일반 관심 종목에는 분할진입과 청산 상태를 적용하지 않는다.

사용자가 일반 관심 종목에서 `관찰 시작`을 누르면 진행 중 영역으로 이동한다.

### 4.3 오늘 종료

당일 관찰이 종료됐거나 매매가 끝난 종목을 보여준다.

장 종료 후 기록은 `Me → 거래·검증 기록`으로 이동한다.

## 5. 관찰 시작 진입 흐름

### 5.1 시작 위치

사용자는 두 번째 `종목` 탭에서 후보 종목과 신호를 확인한다.

신호 카드에는 다음 버튼을 제공한다.

- 상세 보기
- 관찰 시작

### 5.2 관찰 시작 처리

사용자가 `관찰 시작`을 누르면 다음 순서로 처리한다.

1. 현재 종목과 신호 상태를 스냅샷으로 저장한다.
2. 관심 종목 탭의 `진행 중` 영역에 추가한다.
3. 신호의 확인 조건과 무효 조건을 저장한다.
4. 필요한 변화 알림을 활성화한다.
5. 세 번째 관심 종목 탭으로 이동한다.
6. 방금 추가된 관찰 카드를 상단에 표시한다.

안내 문구는 다음과 같이 표시한다.

> 관심 종목에서 관찰을 시작했습니다.  
> 진입 확인·무효·Rally Exit 변화를 알려드립니다.

관찰 시작은 매수 또는 주문 실행을 의미하지 않는다.

사용자가 특정 신호의 변화를 추적하기 시작했다는 의미다.

---

## 6. 중복 관찰 처리

이미 관찰 중인 종목에서 다시 `관찰 시작`을 누르면 새로운 관찰 기록을 생성하지 않는다.

다음 메시지를 표시하고 기존 관찰 카드로 이동한다.

> 이미 관찰 중인 종목입니다.

동일 종목에 여러 전략 신호가 동시에 존재할 수 있다.

예시는 다음과 같다.

- Program Dip Reversal
- Foreign Flow Reversal
- Institutional Accumulation
- Multi-Flow Sync Reversal

그러나 MVP에서는 복잡성과 중복 알림을 줄이기 위해 다음 원칙을 적용한다.

> 종목당 활성 관찰은 한 개만 허용한다.

새로운 신호로 변경하려는 경우 기존 관찰을 종료한 후 새로운 관찰을 시작하도록 한다.

향후 버전에서는 동일 종목의 복수 전략 관찰을 검토할 수 있다.

11. 핵심 수급 지표
11.1 Flow Shift

수급 방향이 전환되는 변곡점을 나타낸다.

양방향 전환을 모두 지원해야 한다.

매도 → 매수 전환
매수 → 매도 전환

예시:

Flow Shift
프로그램 매도 → 매수 전환
7분 전 발생

또는:

Flow Shift
프로그램 매수 → 매도 전환
3분 전 발생
11.2 Flow Sync

프로그램·외국인·기관·개인의 수급 방향이 얼마나 동조하는지 나타낸다.

예시:

Flow Sync
+32, 약한 매수 동조

또는:

Flow Sync
-71, 강한 매도 동조

개인 수급은 반대편 수급 구조를 설명하는 보조 지표로 사용할 수 있다.

단순히 개인 매수 또는 매도를 부정적인 신호로 단정하지 않는다.

11.3 Flow Confidence

현재 신호를 얼마나 신뢰할 수 있는지 0~100 범위로 표시한다.

Flow Confidence는 수익 가능성을 보장하는 확률이 아니다.

다음 요소를 종합한 신호 신뢰도다.

데이터 완전성
수급 지속성
투자주체 간 동조
가격과 수급의 관계
거래대금
신호의 노이즈 수준
확인 조건 충족 정도

예시:

Flow Confidence
78/100
11.4 Flow Divergence

가격과 수급 방향의 불일치를 표시한다.

예시:

Flow Divergence
가격↓ / 프로그램↑

가격은 하락하지만 프로그램 순매수가 증가하는 상태는 반등 후보의 근거가 될 수 있다.

반대로 가격은 상승하지만 프로그램·외국인 수급이 감소하는 경우 청산 검토 근거가 될 수 있다.

11.5 Flow Persistence

현재 수급 방향이 얼마나 오랫동안 유지됐는지 표시한다.

예시:

Flow Persistence
매수 흐름 18분 지속

짧게 발생한 일시적 수급과 일정 시간 유지된 수급을 구분하는 데 사용한다.

11.6 Flow Acceleration

최근 수급 변화 속도가 강화되는지 약화되는지 표시한다.

예시:

Flow Acceleration
최근 5분 매수 강화

또는:

Flow Acceleration
매수 증가 속도 둔화

누적 순매수 금액이 플러스더라도 Flow Acceleration이 약화되면 추가진입에 주의해야 한다.

12. 신호 상태와 사용자 진행 상태 분리

신호 상태와 사용자의 실제 행동 상태는 서로 다르므로 분리해서 관리한다.

Program Dip Reversal 후보를 확인한다.
신호 카드에서 근거와 반대 근거를 확인한다.
관찰 시작을 누른다.
세 번째 관심 종목 탭으로 이동한다.
관찰 시작 스냅샷이 저장된다.
사용자는 진입 확인 조건을 기다린다.
24.2 분할진입
프로그램 순매수가 유지된다.
5분봉이 Envelope 하단에 재진입한다.
직전 5분봉 고가를 돌파한다.
신호 단계가 진입 확인으로 변경된다.
사용자에게 알림이 전달된다.
사용자가 종목을 확인한다.
실제 매수한 경우 1차 진입 기록을 누른다.
이후 조건을 확인하며 최대 4~5회 분할진입을 기록한다.
24.3 추가진입 중단
사용자가 2차 진입까지 기록한다.
프로그램 누적 순매수는 여전히 플러스다.
최근 5분 프로그램 수급이 순매도로 전환된다.
Flow Acceleration이 약화된다.
Flow Confidence가 하락한다.
앱은 추가진입 중단 조건 발생을 표시한다.
사용자는 근거와 반대 근거를 확인한다.
이후 추가진입 여부를 직접 판단한다.
24.4 Rally Exit
가격이 평균 진입가 대비 1~3% 상승한다.
가격이 과매수 또는 Envelope 상단 영역에 진입한다.
프로그램 수급이 매수에서 매도로 전환된다.
외국인 또는 기관도 매도에 동조한다.
Rally Exit 조건이 확인된다.
사용자는 관심 종목 알림을 확인한다.
일부 익절 또는 전량청산 내용을 기록한다.
전량청산하면 해당 종목은 오늘 종료로 이동한다.
24.5 당일청산 확인
사용자의 보유 기록이 남아 있다.
당일청산 기준 시각이 가까워진다.
관심 종목 탭 상단에 청산 확인 카드가 표시된다.
사용자에게 당일청산 확인 알림을 보낸다.
사용자가 실제 청산 내용을 기록한다.
장 종료 후 사후검증 기록으로 연결한다.

26. 핵심 정책
26.1 투자 행동 정책
앱은 매수와 매도를 명령하지 않는다.
사용자의 최종 판단을 대체하지 않는다.
자동으로 사용자의 거래를 실행하지 않는다.

사용자가 기록하지 않은 행동을 추정하지 않는다.

연결이 끊기면 기존 신호도 참고 상태로 변경한다.
최초 관찰 스냅샷을 변경하지 않는다.
신호 계산 버전을 함께 저장한다.
