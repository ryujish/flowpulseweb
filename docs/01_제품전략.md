## 1. 제품 정의

FlowPulse는 외국인·기관·개인·프로그램의 수급 변화를 시간축으로 분석하고, AI가 변화의 의미와 근거·반대 근거·확인 조건·무효 조건을 설명하며, 발생한 신호의 실제 결과까지 검증하는 투자 인사이트 플랫폼이다.

FlowPulse가 답해야 하는 핵심 질문은 다음과 같다.

> 지금 누가 사고 팔고 있으며, 그 흐름이 전환되었는가, 다른 투자 주체도 같은 방향인가, 이 신호는 얼마나 신뢰할 수 있는가, 이후 실제 결과는 어땠는가?

### 핵심 슬로건

> 수급의 시작부터 결과까지 추적하는 AI 투자 인사이트

### 내부 제품 원칙

> 발견에서 끝내지 않고 결과까지 검증한다.

## 2. 해결하려는 문제

기존 증권 서비스는 현재가·차트·투자자별 수급·프로그램 매매 정보를 제공하지만 다음 문제가 남아 있다.

1. 데이터가 여러 화면에 흩어져 있어 장중 변화를 빠르게 파악하기 어렵다.
2. 누적 수치만으로 현재 매수세가 강화되는지 약화되는지 판단하기 어렵다.
3. 가격과 수급이 반대로 움직이는 중요한 상황을 사용자가 직접 찾아야 한다.
4. 외국인·기관·프로그램의 방향이 일치하는지 한눈에 알기 어렵다.
5. AI 설명이 원본 데이터 및 기준 시각과 분리되면 검증하기 어렵다.
6. 발생한 신호가 실제로 유효했는지 사후 결과가 축적되지 않는다.
7. 직장인이나 장중 화면을 계속 보기 어려운 사용자는 신호 변화와 청산 시점을 놓치기 쉽다.

FlowPulse는 단순히 더 많은 숫자를 보여주는 것이 아니라, 중요한 변화를 탐지하고 해석 가능한 상태로 제공하여 이 문제를 해결한다.

## 3. 목표 사용자

### 핵심 사용자

- 장중 외국인·기관·프로그램 수급을 확인하는 개인투자자
- 수급은 보지만 숫자의 의미와 지속성을 판단하기 어려운 사용자
- 하루 종일 차트를 보기 어렵고 짧은 시간에 핵심 변화를 확인하려는 직장인
- 자동매매보다 근거와 조건을 확인한 후 직접 판단하려는 사용자
- 자신의 매매 가설을 소량 또는 모의 기록으로 검증하려는 사용자

### 초기 비목표 사용자

- AI가 수익을 보장하거나 종목을 대신 선택하기를 기대하는 사용자
- 완전 자동주문·초단타 자동매매 시스템을 원하는 사용자
- 근거 확인 없이 매수·매도 지시만 원하는 사용자

## 4. 제품 포지셔닝

FlowPulse의 경쟁 범주는 일반 증권 앱, 조건검색기, 수급 분석 서비스, 종목 커뮤니티, AI 투자 해설 서비스다.

FlowPulse는 이들을 단순 결합하지 않는다. 다음의 연결 구조로 차별화한다.

```text
실시간 수급 변화 탐지
→ 독자 지표 계산
→ 근거 기반 AI 해설
→ 확인·무효 조건 제시
→ 사용자 판단과 기록
→ 신호 결과 자동 검증
→ 다음 신호 평가에 반영
```

### 제품 포지셔닝 문장

> FlowPulse는 수급 숫자를 조회하는 도구가 아니라, 수급의 방향 전환과 주체 간 동조를 발견하고 신뢰도를 평가한 뒤 실제 결과까지 검증하는 AI 투자 판단 플랫폼이다.

## 5. 핵심 가치 제안

### 빠른 발견

- 앱 실행 후 30초 안에 시장의 핵심 수급 상태를 파악한다.
- 누적 수치보다 방향 전환·가속·동조·괴리를 우선 표시한다.

### 설명 가능한 판단

- AI 해설에 기준 시각과 원본 데이터를 연결한다.
- 근거뿐 아니라 반대 근거를 함께 보여준다.
- 다음 확인 조건과 해석의 무효 조건을 명시한다.

### 결과 검증

- 신호 발생 당시 데이터와 해설을 고정 저장한다.
- 10분·30분·종가·1거래일·5거래일 결과를 추적한다.
- 표본 수, 거래비용, 슬리피지, 시장 국면 등 검증의 한계를 함께 표시한다.

### 짧고 규칙적인 사용

- 사용자가 화면을 계속 보지 않아도 중요한 상태 변화를 알림으로 확인할 수 있게 한다.
- 알림은 불안을 자극하거나 잦은 거래를 유도하지 않고, 사용자가 설정한 확인·무효·청산 조건을 중심으로 제공한다.

## 6. 필수 독자 지표

다음 세 지표는 선택 기능이 아니라 MVP P0 필수 기능이다.

### 6.1 Flow Shift

투자 주체별 매수·매도 방향이 전환되는 변곡점을 탐지한다.

- Bullish Shift: 매도 우위에서 매수 우위로 전환
- Bearish Shift: 매수 우위에서 매도 우위로 전환
- Weakening Sell: 매도는 유지되지만 압력이 감소
- Weakening Buy: 매수는 유지되지만 압력이 감소
- Neutral: 방향이 불명확하거나 신뢰도 부족

`매도 약화`와 `매수 전환`, `매수 약화`와 `매도 전환`은 반드시 구분한다.

### 6.2 Flow Sync

외국인·기관·프로그램이 같은 방향으로 움직이는 동조 강도를 측정한다.

- Bullish Sync: 여러 주체의 동시 매수
- Bearish Sync: 여러 주체의 동시 매도
- Divergent: 주체별 방향 충돌
- Neutral: 동조성 부족 또는 데이터 부족

방향과 강도를 함께 표현할 수 있도록 `-100~+100` 범위를 우선 검토한다. 최종 계산식과 점수 구간은 백테스트 후 확정한다.

### 6.3 Flow Confidence

예측 상승률이 아니라 현재 데이터와 신호를 얼마나 신뢰할 수 있는지를 평가한다.

평가 요소에는 데이터 완전성·지연 여부·표본 규모·신호 지속성·시간축 일치도·가격 및 거래량 확인·과거 유사 신호 표본을 포함한다.

신뢰도가 기준 미달이면 강한 신호로 표시하지 않으며, 데이터 부족 상태에서는 AI 해설을 생성하지 않거나 불확실성을 명확히 표시한다.

## 7. 보조 분석 지표

핵심 지표를 설명하고 복합 신호를 구성하기 위해 다음 지표를 단계적으로 도입한다.

| 지표 | 역할 |
|---|---|
| Flow Persistence | 현재 수급 방향의 지속성 측정 |
| Flow Divergence | 가격과 수급이 반대로 움직이는 괴리 탐지 |
| Flow Acceleration | 순매수·순매도 변화 속도와 가속도 측정 |
| Flow Impact | 수급이 가격 변화에 미치는 상대적 영향 측정 |

보조 지표는 MVP 화면을 복잡하게 만들지 않도록 기본 화면에서는 요약하고 상세 분석에서 근거로 제공한다.

## 8. 투자 주체별 공통 신호 엔진

`과매도 상태에서 특정 투자 주체의 매수가 유입되는 상황`과 `과매수 상태에서 해당 주체의 매도가 유입되는 상황`은 프로그램뿐 아니라 외국인·기관·개인에도 같은 기본 구조로 적용한다.

### 8.1 공통 신호 모델

```text
Actor Dip Reversal
가격 과매도 + 선택 주체의 매수 유입·유지
→ 조건부 분할 진입 관찰

Actor Rally Exit
가격 과매수 + 선택 주체의 매수 둔화·매도 전환
→ 분할익절·전량청산 관찰
```

`Actor`에는 프로그램·외국인·기관·개인을 대입할 수 있다.

| 투자 주체 | 과매도 매수 유입 신호 | 과매수 매도 유입 신호 |
|---|---|---|
| 프로그램 | Program Dip Reversal | Program Rally Exit |
| 외국인 | Foreign Dip Reversal | Foreign Rally Exit |
| 기관 | Institution Dip Reversal | Institution Rally Exit |
| 개인 | Retail Dip Reversal | Retail Rally Exit |

다만 모든 주체를 동일한 가중치와 임계값으로 계산하지 않는다. 투자 주체별 거래 특성·데이터 제공 주기·추정 여부·종목별 영향력이 다르므로 각각 별도의 기준과 사후검증 결과를 사용한다.

특히 개인 수급은 외국인·기관과 반대되는 잔여 흐름으로 나타날 수 있으므로, 개인 순매수 자체를 무조건 긍정 신호로 해석하지 않는다. 가격과 개인 수급의 관계, 외국인·기관·프로그램의 반대 방향, 시장 국면을 함께 평가한다.

데이터가 실시간 확정값인지 장중 추정값인지, 갱신 주기와 지연시간이 얼마인지는 신호 카드와 Flow Confidence에 반영한다. 실제 제공 가능 범위는 데이터 공급사 계약 및 API 검증 후 확정한다.

### 8.2 Program Dip Reversal

> 가격이 단기 과매도 상태에 있지만 프로그램 매수가 유입되거나 유지되고, 가격 반전 조건이 확인될 때 발생하는 프로그램 수급 추종형 데이트레이딩 관찰 신호

#### 기본 탐색 가설

- 당일 하락 종목
- 프로그램 누적 순매수 기준 충족
- 프로그램 순매수/거래대금 비율 기준 충족
- 30분 Envelope 하단 이탈
- 5분 Envelope 하단 이탈 또는 재진입
- 최근 5분·15분 프로그램 매수 흐름 유지
- 프로그램 Bullish Shift 또는 매수 지속 상태
- 최소 거래대금 및 유동성 기준 충족

고정 순매수 금액만 사용하지 않고 종목별 거래대금과 유동성을 함께 평가한다. 정확한 임계값은 검증 전까지 확정하지 않는다.

#### 운영 가설

- 최대 4~5회 조건부 분할 진입
- 가격 하락만을 이유로 추가매수하지 않음
- 수급 유지와 가격 확인 조건이 충족될 때만 다음 진입 단계 활성화
- 프로그램 Bearish Shift, 당일 저점 이탈, 데이터 이상 발생 시 추가매수 중단
- 목표 수익 구간은 1~3%를 우선 검증
- 다음 거래일까지 보유하지 않고 당일 전량청산

이 규칙은 매수 권유나 수익 보장이 아니라 검증 대상인 전략 가설이다.

### 8.3 Program Rally Exit

> 보유 종목이 단기 과매수 상태에 진입하고 프로그램 매수세가 둔화하거나 순매도로 전환될 때 수익을 보호하는 동적 익절 신호

#### 주요 조건

- 5분 또는 30분 Envelope 상단 접근·이탈 후 재진입
- 프로그램 매수 가속도 둔화
- 최근 5분 프로그램 순매도 전환
- 프로그램 Bearish Shift
- 직전 고점 돌파 실패 또는 단기 가격 반락
- Flow Confidence 기준 충족

#### 청산 구조

1. 과매수와 프로그램 매수 둔화가 확인되면 일부 수익 보호
2. 프로그램 Bearish Shift가 확인되면 추가 분할청산
3. 프로그램 매도가 지속되고 가격 확인 조건까지 발생하면 잔여 수량 청산
4. 신호가 발생하지 않더라도 손절 조건 또는 장 마감 전 지정 시각에 전량청산

`Program Rally Exit`은 고정 1~3% 익절을 완전히 대체하지 않는다. 고정 수익 구간, 프로그램 수급 전환, 가격 손절, 수급 손절, 시간청산을 함께 검증한다.

### 8.4 전략의 대칭 구조

| 구분 | 진입 관찰 | 익절 관찰 |
|---|---|---|
| 전략명 | Program Dip Reversal | Program Rally Exit |
| 가격 상태 | 과매도 | 과매수 |
| 프로그램 상태 | 순매수 유입·유지 | 매수 둔화·순매도 유입 |
| Flow Shift | Bullish Shift | Bearish Shift |
| 행동 | 조건부 분할 진입 검토 | 분할익절·전량청산 검토 |

## 9. Playbook 제품화 전략

공통 신호 엔진에서 검증된 대표 전략은 단순 조건검색식이 아니라 `FlowPulse Playbook`으로 제공한다.

### Playbook 01: 프로그램 과매도 반등

1. 전략 가설과 위험 설명
2. 현재 조건 충족 후보
3. 진입 전 확인 항목
4. 최대 4~5회 분할 진입 기록
5. 프로그램 매수 유지·둔화·전환 상태
6. 추가매수 중단 및 무효 조건
7. 익절·손절·시간청산 상태
8. 10분·30분·종가 결과
9. 과거 유사 신호의 표본 수와 손익분포
10. 모의 기록 또는 최소 수량 검증 기록

FlowPulse는 주문을 자동 실행하지 않는다. MVP에서는 신호·근거·상태 변화·알림·기록을 제공하고 매매 판단과 주문은 사용자가 직접 수행한다.

### 후속 Playbook 확장

Program Playbook의 검증 구조를 그대로 복사하지 않고, 각 투자 주체별로 별도 백테스트를 거쳐 다음 순서로 확장한다.

1. Program Dip Reversal / Program Rally Exit
2. Foreign Dip Reversal / Foreign Rally Exit
3. Institution Dip Reversal / Institution Rally Exit
4. Retail Dip Reversal / Retail Rally Exit
5. 외국인·기관·프로그램이 함께 전환되는 Flow Sync 복합 Playbook

## 10. 핵심 사용자 경험

```text
앱 실행
→ 시장 Flow 브리핑 확인
→ Program Dip Reversal 후보 발견
→ 근거·반대 근거·확인·무효 조건 확인
→ 사용자가 직접 판단 및 분할 진입 기록
→ 프로그램 수급 변화 알림 수신
→ Program Rally Exit 또는 위험 조건 확인
→ 당일 청산 기록
→ 10분·30분·종가·후속 결과 자동 검증
```

### 하단 메뉴

| 메뉴 | 역할 |
|---|---|
| Flow | 시장 핵심 수급, 독자 지표, AI 브리핑, 대표 신호 |
| 종목 | 검색, 관심 종목, 종목별 수급·Playbook 상태 |
| AI | 근거 기반 시장·수급 질의와 유사 신호 분석 |
| Feed | 국내주식·해외주식·자유 커뮤니티 |
| Me | 관심 종목, 알림, 전략 기록, 작성 글, 설정 |

종목별 토론은 별도 최상위 게시판으로 분리하지 않고 종목 상세에 연결된 Feed로 제공한다.

## 11. AI 해설 전략

모든 핵심 해설은 다음 구조를 따른다.

1. 무엇이 변했는가
2. 어떤 데이터가 근거인가
3. 평소보다 얼마나 이례적인가
4. 반대되는 데이터는 무엇인가
5. 다음 확인 조건은 무엇인가
6. 어떤 상황에서 해석이 무효가 되는가
7. 데이터와 신호의 신뢰도는 어느 정도인가

AI는 데이터·계산된 분석 결과·AI 해석을 구분하여 표시한다. 근거가 부족하면 단정적인 설명이나 매수·매도 지시를 생성하지 않는다.

---

## 12. 알림 전략

알림은 화면을 계속 보기 어려운 사용자가 미리 정한 조건의 변화를 짧게 확인하도록 돕는다.

- Program Dip Reversal 후보 발생
- 진입 확인 조건 충족
- 프로그램 매수 유지 또는 강화
- 프로그램 매수 둔화
- 추가매수 중단 조건 발생
- Program Rally Exit 발생
- 손절·무효 조건 발생
- 장 마감 전 청산 시각 알림

과도한 거래를 유도하는 자극적 표현, 수익 보장 표현, 불필요한 반복 알림은 사용하지 않는다.

## 13. 데이터 및 기술 전략

### 데이터 역할 분리

- 현재가·분봉·호가·체결·투자자별 수급·프로그램 매매: 증권사 API
- 기업공시·재무정보: OpenDART
- 시장조치·공식 시장정보: KRX 및 KIND

- 독자 지표·복합 신호·사후검증: FlowPulse 자체 분석

개인용 API는 본인 전용 폐쇄 환경의 MVP 검증에만 사용한다. 외부 사용자에게 제공하기 전에 데이터 조회·저장·가공·재배포 권한을 계약으로 확인한다.

### 기술 방향

| 영역 | 전략 |
|---|---|
| 프런트엔드 | React + TypeScript 반응형 웹앱 |
| 모바일 앱 | Capacitor 기반 iOS·Android WebView |
| 서버 | NestJS |
| 데이터베이스 | PostgreSQL + TimescaleDB |
| 실시간 처리 | WebSocket + Redis |

수집 서버는 개발자 노트북의 종료·절전과 무관하게 상시 실행되어야 한다. 연결 상태, 마지막 갱신 시각, 지연 및 누락 여부를 사용자에게 표시한다.

## 15. 사업 및 성장 전략

### 초기 성장 구조

1. 대표 Playbook의 신호와 사후검증을 축적한다.
2. 사용자가 모의 또는 최소 수량으로 전략 가설을 검증하도록 돕는다.
3. 검증 결과를 이해하기 쉬운 카드로 제공한다.
4. 데이터가 연결된 Feed에서 결과와 해석을 공유한다.
5. 신뢰도 높은 신호와 설명이 재방문 이유가 되도록 한다.

### 수익모델 후보

- 무료: 지연 데이터, 기본 Flow 지표, 제한된 관심 종목과 신호 기록
- 유료: 실시간 범위, 고급 Playbook, 맞춤 알림, 장기 사후검증, 유사 신호 분석
- B2B: 증권사·투자 플랫폼용 지표·설명·검증 모듈 제공

가격과 실제 제공 범위는 데이터 계약 비용과 금융 규제 검토 후 확정한다.

- 데이터 지연·누락 발생률
- 잘못된 신호 계산 및 정정률
- AI 근거 연결률
- 신호별 Flow Confidence 보정 정확도
- 사후검증 완료율

### 전략 검증 지표

- 신호 발생 횟수와 표본 수
- 10분·30분·종가·1일·5일 수익률 분포
- 최대 유리 변동폭과 최대 불리 변동폭
- 거래비용·슬리피지 반영 손익분포
- 시장 국면·종목 규모·거래대금별 결과
- 고정 익절과 Program Rally Exit의 결과 비교

승률만으로 전략을 평가하지 않는다. 평균 손익, 손익비, 최대 손실, 표본 수, 체결 가능성을 함께 본다.

## 17. 핵심 가설과 검증 과제

### 제품 가설

> 사용자는 누적 수급 숫자만 볼 때보다 방향 전환·동조·신뢰도와 근거 기반 해설을 함께 볼 때 시장 상황을 더 빠르고 일관되게 판단할 수 있다.

### 대표 전략 가설

> 가격이 과매도 상태일 때 프로그램 매수 유입과 지속성을 확인하고 조건부로 분할 진입한 뒤, 과매수와 프로그램 매도 전환을 이용해 당일 청산하면 단순 Envelope 조건만 사용할 때보다 위험 조정 결과가 개선될 수 있다.

이는 아직 검증되지 않은 가설이다. 다음 항목을 데이터로 확인해야 한다.

1. 프로그램 누적 순매수 절대금액과 거래대금 대비 비율 중 어떤 기준이 유효한가
2. 5분·15분 변화량의 최적 조합은 무엇인가
3. Envelope 설정값이 종목과 시장 국면별로 유효한가
4. 4회와 5회 분할 진입 중 어느 방식이 유리한가
5. 고정 1~3% 익절과 Program Rally Exit의 조합이 유효한가
6. 가격·수급·시간 손절 기준은 어떻게 설정해야 하는가
7. 거래비용과 슬리피지 반영 후에도 결과가 유지되는가
