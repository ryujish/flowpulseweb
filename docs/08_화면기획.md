## 1. 문서 목적

이 문서는 FlowPulse MVP의 사용자 화면과 관리자 화면을 실제 구현 가능한 수준으로 정의한다.

각 화면에 대해 다음을 명시한다.

- 화면 목적
- 진입 경로
- 핵심 사용자 질문
- 정보 우선순위
- 주요 컴포넌트
- 사용자 행동
- 상태 변화
- 빈 상태·오류·데이터 지연
- 모바일·PC 반응형 배치
- MVP 완료 기준

화면의 목표는 데이터를 많이 보여주는 것이 아니라 사용자가 짧은 시간 안에 수급 변화와 위험을 이해하고 자신의 판단과 결과까지 추적하게 하는 것이다.

---

## 2. 화면 설계 원칙

1. 위험·데이터 오류·무효 조건을 수익 기회보다 먼저 보여준다.
2. 핵심 상태는 30초 안에 이해할 수 있어야 한다.
3. 원본 데이터·Flow 지표·AI 해석을 구분한다.
4. 근거와 반대 근거를 같은 화면 깊이에 배치한다.
5. 신호마다 기준 시각과 데이터 상태를 표시한다.
6. 진입과 청산을 같은 Playbook 흐름으로 연결한다.
7. 가격 하락만으로 추가 진입을 유도하지 않는다.
8. 자동주문·AI 자동매매 UI를 제공하지 않는다.
9. 모바일을 우선하되 PC에서는 차트와 상세 분석을 확장한다.
10. 색상만으로 상승·하락·매수·매도를 구분하지 않는다.

## 4. 전역 앱 셸

### 모바일

- 상단: 화면 제목, 데이터 상태, 검색·알림
- 본문: 세로 스크롤
- 하단: Flow·종목·AI·Feed·Me
- 중요 상태: 상단 고정 배너
- 기록 입력: 하단 시트

### PC

- 좌측: 전역 메뉴
- 중앙: 주요 콘텐츠
- 우측: 신호·AI·기록 컨텍스트 패널
- 데이터 상태: 상단 상태 바

### 전역 하단 메뉴

```text
Flow | 종목 | AI | Feed | Me
```

현재 메뉴는 아이콘과 텍스트를 함께 표시한다.

## 5. 전역 데이터 상태 바

### 정상

```text
장중 · 실시간 · 마지막 갱신 10:24:15
```

### 추정·지연

```text
외국인·기관 수급은 장중 추정값입니다 · 10:23
```

### 장애

```text
프로그램 데이터가 47초 동안 갱신되지 않았습니다.
신규 신호 계산을 일시 중단했습니다.
```

### 규칙

- 정상 상태는 한 줄로 축약한다.
- STALE·MISSING은 화면 상단 고정 배너로 확장한다.
- 장애 배너를 닫아도 작은 상태 아이콘을 유지한다.
- 오류 발생 중 새로운 강한 신호를 강조하지 않는다.

## 9. S03 Flow 홈

### 사용자 질문

> 지금 시장에서 가장 중요한 수급 변화는 무엇인가?

### 모바일 구성 순서

1. 데이터·장 상태
2. 오늘 시장 한 문장
3. 시장 Flow 요약
4. 위험·청산 카드
5. Program Playbook 후보
6. 수급 급변 종목
7. 관심 종목
8. 최근 검증 결과

### 오늘 시장 한 문장

```text
외국인 매도는 약해지고 프로그램 매수는 강화되지만 기관 동조는 아직 제한적입니다.

기준 10:24 · Confidence 82
```

문장을 선택하면 근거와 반대 근거를 펼친다.

### 시장 Flow 요약

| 주체 | 상태 | 최근 변화 |
|---|---|---|
| 외국인 | 매도 약화 | 최근 15분 개선 |
| 기관 | 매수 유지 | +0.4억원 |
| 개인 | 순매도 | 방향 반대 |
| 프로그램 | 매수 강화 | 최근 5분 +1.1억원 |

하단에 다음을 표시한다.

```text
Core Flow Sync +41 · 약한 매수 동조
Flow Confidence 82/100
```

### 카드 우선순위

1. 데이터 장애
2. 마감 전 당일청산
3. Hard Invalidation
4. Rally Exit
5. Dip Entry Confirmed
6. Dip 후보
7. 일반 시장 브리핑

### PC 배치

- 좌측: 시장·후보 목록
- 중앙: 지수와 시장 수급 차트
- 우측: 중요 신호와 AI 브리핑

## 12. Program Dip Reversal 카드

### 목록 축약형

```text
Program Dip Reversal
반전 확인 대기 · 10:24

프로그램 누적    +8.2억원
최근 5분         +1.1억원

Shift   매수 유지     Sync +32
```

- 무효: 빨간색 외에 `무효` 텍스트·아이콘

### 금지 표현

- 지금 매수
- 급등 확정
- 성공 확률 78%

### 무효 조건

화면 스크롤과 무관하게 상단 또는 하단 고정 요약으로 접근 가능하게 한다.

- 원본 입력값
- 점수 구성
- Reason Code
- 지표 버전

상세 데이터는 접기 가능하다.

## 45. 화면기획 선언

> FlowPulse의 화면은 사용자를 더 자주 거래하게 만들기 위한 것이 아니다. 중요한 수급 변화와 위험을 빠르게 이해하고, 사용자가 자신의 규칙에 따라 판단하고 결과를 검증하게 만드는 도구다.
